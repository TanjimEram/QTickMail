Background: This Check in system was created for our national and international events for smooth check in of participants which enabled us to check in 850+ participants in a span of an hour. 

Steps:
-Make a google sheet. Copy and past the typescript code in extension/typescript.
-Make a deployment.
-Add the WebApp url and the link of the drive where the generated QR are to stored.

A few things to consider:
-The data inputs should be changed in the code to your need.
-The sheet must contain an 'Attendance' sheet.
